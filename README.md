# 🎯 Event Stuff

A collection of everything I learn, build, and explore through different events, hackathons, game jams, workshops, and tech-related activities.

## 📌 About

This repository serves as my personal archive of event-based learning and experimentation. It contains projects, code, resources, experiments, and other stuff that I work on while participating in different events.

Instead of letting my event work get lost across different folders and repositories, I keep everything organized here so I can revisit it, learn from it, and track my progress as a developer.

## 📂 What's Inside?

- 🎮 **Game Jams** — Game prototypes, mechanics, experiments, and assets.
- 💻 **Hackathons** — Projects, implementations, and technical experiments.
- 🛠️ **Workshops** — Code, exercises, and concepts learned.
- 🚀 **Tech Events** — Anything interesting I build or explore during events.
- 📚 **Learning Resources** — Notes, references, and useful materials.
- 🧪 **Experiments** — Random ideas, prototypes, and things I try out.

## 🧰 Tech Stack

The technologies used here may vary depending on the event and project.

- C++
- GDScript / Godot Engine
- Python
- Git & GitHub
- Other tools and technologies as required

## 🎯 Purpose

- Learn by building real things.
- Experiment with new technologies and ideas.
- Keep track of my progress as a developer.
- Preserve my work from different events in one place.
- Explore, make mistakes, fix bugs, and improve.

## 📈 Philosophy

**Learn something. Build something. Break something. Fix it. Repeat.**

Not everything here will be polished or production-ready. Some projects may be incomplete, experimental, or simply created to understand a concept. That's part of the learning process.
